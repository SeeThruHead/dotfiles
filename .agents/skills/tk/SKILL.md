# tk — Ticket Management

Use the `tk` CLI for all ticket/task tracking. Never use the built-in TaskCreate/TaskUpdate tools.

Run `tk --help` or `tk <command> --help` to discover available commands and flags.

## When invoked as `/tk $ARGUMENTS`

Run: `tk $ARGUMENTS`

If no arguments, run `tk ls` to show current tickets.
